# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
There is no tagged release. Each entry is a merged pull request, and the date is the merge commit.

The initial commit on 2026-10-31 added only the title line of the README.

## [Unreleased]

### Changed

- The web page tells the model today's date in Europe/Copenhagen. `i fjor` and `sidste måned` are Statbank codes (`2025`, `2026M10`). `seneste 10 år` is the latest published period and the same quarter or month 10 years earlier (`2016K3` to `2026K3`). Ollama thinking is off unless `STATBANK_LLM_THINK=1` (`reasoning_effort` is `none`). The default local model is `gemma4:26b-a4b-it-qat`. xAI requests are unchanged.
- `i år`, `i fjor`, `sidste år`, and `sidste måned` follow today's calendar. A period that is not published is an error naming that period and the latest one in the table. A derived figure in the page is kept only when the sentence names the values and they are one measure; a sum also has to be one period.
- Search maps `arbejdsløshed` and `ledighed` to the Fuldtidsledige tables, so the AUS tables come first. A hyphenated query also matches a title that joins the parts or writes them separately. A complete year on a quarterly or monthly table is one figure: flows are added, levels are averaged, and the note says which. An unclear measure, or a year that is missing a period, is left as separate periods. Danish period phrases (`i år`, `i fjor`, `sidste år`, `sidste kvartal`, `seneste`, month names, `3. kvartal 2025`, `K3 2025`) resolve from the latest period in the table. A fremskrivning table and a prognose row are marked `projection` in the tools and on the page. The number guard keeps a difference, sum, or percentage change that follows from the fetched values, and still hides invented numbers and a value paired with the wrong period or row.

### Added

- **Make the web page host-ready for a public demo** ([#13](https://github.com/tottedk/statistikbanken-mcp/pull/13), 2026-11-01). A Dockerfile runs `statistikbanken-web` as a non-root user, installing from `uv.lock` on Python 3.12. The process reads `PORT` when a platform sets it, otherwise `STATBANK_PORT`. `GET /healthz` returns 200 and does not call the model or Statistikbanken. `STATBANK_PUBLIC=1` forces xAI, ignores Ollama, and tightens the limits (40 questions a day, 3 per minute, 6 tool calls, 300 characters, two questions at once, and a 2048-token `max_tokens` cap on each xAI request). The xAI model is `STATBANK_XAI_MODEL` (default `grok-4`, which may be retired, so it is chosen at deploy time). The page shows a short Danish demo line. The daily count is kept in memory and resets when the process sleeps or restarts. `STATBANK_STATE_FILE`, when set, stores that count and the date. The hard spending cap is the prepaid xAI credit. `STATBANK_DAILY_CAP=0` stops the demo with a closed message. The per-minute limit reads `CF-Connecting-IP` or the last `X-Forwarded-For` entry only when `STATBANK_PROXY_SECRET` is set and the request carried `X-Proxy-Secret`, and visitor addresses are not logged. That secret, when set, is also required on every route except `/healthz`. The MCP subprocess does not receive `XAI_API_KEY` or other secrets. Responses send `Content-Security-Policy: frame-ancestors` (from `STATBANK_FRAME_ANCESTORS`, default `'self'`), `X-Content-Type-Options: nosniff`, and `Referrer-Policy: no-referrer`. No cookies.

- **Web: add a Basis/Avanceret view toggle** ([#10](https://github.com/tottedk/statistikbanken-mcp/pull/10), 2026-11-01). The local page has two views. Basis is the default and shows the answer and a compact table (one row per period, one column per series, such as Esbjerg, 80+). It hides the chart, the downloads, the source link, and the tool-call list, including when there are no rows and on an error. Avanceret adds the chart, the source line with table id and title, and the tool calls. Under the table it offers CSV, Excel, and JSON, plus a PNG of the chart when a chart is shown. Excel and JSON are built from the facts already on the page (`POST /api/export`) and do not ask the model or Statistikbanken again. Periods are shown as `2015 1. kvt.`, `marts 2015`, `2015 1. halvår`, or the year. CSV and Excel use that label. JSON keeps the raw code in `periode` and adds `periode_label`. Unknown codes are left as they are. A friendly form of a fetched period is not treated as an extra figure. The choice is stored in the browser. Switching redraws the last answer and does not send a new question. The number, age, and place guards are otherwise unchanged.

- **Add a chart, CSV download, and table links** ([#7](https://github.com/tottedk/statistikbanken-mcp/pull/7), 2026-10-31). When one answer has several periods in the same series, the page draws a line chart. Several places become several lines. CSV downloads the rows as UTF-8 with a BOM, semicolons, and a decimal comma. Each table links to `https://www.statistikbanken.dk/` plus the table id. A number in the prose was kept when it appeared in the question or anywhere in that turn's tool results. An invented figure replaced the prose. Digits inside a table id are not figures. The question decides the age: `80+`, `over 80`, and `80 år og derover` become `sum_from`, and `0-17`, `mellem N og M`, or `børn` become `sum_range`, replacing the ALDER codes the model sent. If the fetched age or municipality is a different one, the answer says so and the cards, chart, and CSV are hidden. The page's own line includes the dimensions. A model timeout, including one wrapped in an exception group, is HTTP 504.

- **Add a local web page over the MCP server** ([#6](https://github.com/tottedk/statistikbanken-mcp/pull/6), 2026-10-31). A Danish page on 127.0.0.1 asks one question and shows the answer, the numbers (table, period, unit), and each MCP tool call. The page is an MCP client over stdio. The model is an OpenAI-compatible chat-completions endpoint: Ollama by default, or xAI when `--llm xai` and `XAI_API_KEY` are set. In-memory limits cover question length, a per-address rate, and a daily cap.

- **Add an MIT licence** ([#5](https://github.com/tottedk/statistikbanken-mcp/pull/5), 2026-10-31). Adds `LICENSE`, Copyright (c) 2026 Thomas Jensen. `pyproject.toml` sets `license = "MIT"` and `license-files = ["LICENSE"]`. The README links to that file.

- **Sum a closed age range and show what a table measures** ([#2](https://github.com/tottedk/statistikbanken-mcp/pull/2), 2026-10-31). `hent_data` can total a closed run of numeric codes. `sum_range` `{"ALDER": ["0", "17"]}` sends the API's own `sum()` and returns one figure labelled `0-17`. `sum_from` is unchanged. Each data result includes `title`, `description`, `unit`, and `periods`. A search for associations still returns `IDRFOR01`, whose title is sports clubs and memberships, not every association and not unique persons.

- **Add a Statistikbanken MCP server** ([#1](https://github.com/tottedk/statistikbanken-mcp/pull/1), 2026-10-31). An MCP server (stdio) for Danmarks Statistik's open Statistikbanken API. No API key. `find_tabel` searches the published table list by id, title, and variable name. `tabelinfo` returns variables and value codes, and collapses long numeric runs such as ages 0–125. `hent_data` fetches rows. Unknown table ids and value codes become a short message naming the bad code and which tool to call next. Ages in FOLK1A are single years, so `sum_from` (for example `{"ALDER": "80"}`) sends the API's own `sum()` and comes back as one figure labelled `80+`. Recorded responses from the live API back the unit tests. Live tests, including one stdio client session, hit `https://api.statbank.dk`. CI runs ruff and pytest.

### Changed

- **Check a prose figure against the period or place named with it.** Pairing flags a number only when that number is itself a fetched row value and the same clause ties it to a different period or row. `94.486` beside `2013K1` is dropped when that figure belongs to `2014K1`. A figure that comes from the question or a label, such as `80` in `(80+)` or `10` in `10 år`, or that is not in the rows, keeps the ordinary check. Friendly names (`2014 1. kvt.`, `marts 2015`) and codes (`2014K1`) are that period.

- **Find ordinary subjects, and state the period range when a code is outside it.** `find_tabel` maps togpassagerer, vareeksport, dødsårsager, kræft, gini, nye virksomheder, iværksættere, månedsfortjeneste, AKU, påbegyndte boliger, and unemployed or jobless onto the words the catalogue uses. Danmark, Denmark, and Danish no longer count when the query also names a subject. An unknown place such as Lyngby suggests the hyphenated name (Lyngby-Taarbæk) and is not accepted on its own. An unknown period states the available range instead of a near-miss code, and a bare year on a quarterly or monthly table suggests that year's sub-periods.

- Examples use Esbjerg and Viborg.

- **Simplify the Statistikbanken client and rank income before tax** ([#14](https://github.com/tottedk/statistikbanken-mcp/pull/14), 2026-11-01). `statbank.py` drops the separate alias, sum-string, and time-sum helpers that repeated the same work. `find_tabel` strips punctuation stuck to a word, drops a trailing e on a long Danish word, and splits a compound on the linking s (`gennemsnitsindkomst` into gennemsnit and indkomst) only as a weaker fallback, so a whole-word hit outranks a piece. When the query says "før skat", a title of "Indkomst i alt" is preferred to "Disponibel indkomst"; if the query also names a breakdown such as køn, that preference is only a tie-breaker. INDKP105 is in the top three for "gennemsnitlig indkomst før skat", "indkomst i alt før skat", and "gennemsnitsindkomst før skat".

- **Round chart ticks, label export dimensions, and crop the PNG** ([#12](https://github.com/tottedk/statistikbanken-mcp/pull/12), 2026-11-01). The chart y-axis uses about five ticks on a 1-2-5 grid, written with a Danish thousands separator, and the scale covers the smallest and largest value. CSV, Excel, and JSON use the same dimension label as the table (`Esbjerg, 80+`). JSON also keeps the raw dimensions in `dimensioner_rå`. The PNG is cropped to the chart, including the legend, instead of leaving an empty margin on the right.

- **Tighten the web prose number guard to fetched rows** ([#9](https://github.com/tottedk/statistikbanken-mcp/pull/9), 2026-11-01). A number in the model's prose is kept only when it is in the question, a fetched `hent_data` value (Danish formats included), a period or row label from those rows, the fetched table title, or a variable value the model passed in that turn's `hent_data` arguments. Figures that show up only in `tabelinfo` or `find_tabel` are suppressed. The prompt tells the model to name areas and categories rather than quote their codes.

- **Log flagged numbers and ask for start and end values only** ([#8](https://github.com/tottedk/statistikbanken-mcp/pull/8), 2026-10-31). When the number guard drops a multi-series answer, the server logs the flagged figures at INFO and does not log the sentence. The system prompt tells the model to quote only the first and last value of each series, and not to compute a difference or a percentage.

- **Rewrite the README for a first read** ([#4](https://github.com/tottedk/statistikbanken-mcp/pull/4), 2026-10-31). README only. It states what the server is, shows three calls checked against the live API on 31 October 2026, and records the 50-question run plus the limits that remain. No software licence was added. The data note points at Danmarks Statistik's own CC BY 4.0 terms.

- **Make table search and data errors usable** ([#3](https://github.com/tottedk/statistikbanken-mcp/pull/3), 2026-10-31). The three tools stay the same. `find_tabel` ranks partial matches, a small synonym list (`bruttoledighed`, `huspriser`, `husdyr`, `population`, `indbrud`, and a few English equivalents), and FOLK1A municipality names. A miss returns an error that suggests a broader query. `hent_data` accepts value labels, suggests close matches, names the latest period when a period is missing, fills a required total into `defaults`, and lists codes when a required variable has no total. `sum_range` also adds an explicit list of codes. If the API refuses the sum, the rows are fetched and added here. A trailing 0 in a series is marked `unpublished`. `tabelinfo` summarises time as first, last, and count, caps long value lists, and takes `values_filter`. Value labels are not indexed for every table, only FOLK1A areas. Equal search scores keep catalogue order.

## [Unreleased]

### Added

- **Web: add a Basis/Avanceret view toggle** ([#10](https://github.com/tottedk/statistikbanken-mcp/pull/10), 2026-11-01). The local page has two views. Basis is the default and shows the answer and a compact table (one row per period, one column per series, such as Rudersdal, 80+). It hides the chart, the downloads, the source link, and the tool-call list, including when there are no rows and on an error. Avanceret adds the chart, the source line with table id and title, and the tool calls. Under the table it offers CSV, Excel, and JSON, plus a PNG of the chart when a chart is shown. Excel and JSON are built from the facts already on the page (`POST /api/export`) and do not ask the model or Statistikbanken again. Periods are shown as `2015 1. kvt.`, `marts 2015`, `2015 1. halvår`, or the year. CSV and Excel use that label. JSON keeps the raw code in `periode` and adds `periode_label`. Unknown codes are left as they are. A friendly form of a fetched period is not treated as an extra figure. The choice is stored in the browser. Switching redraws the last answer and does not send a new question. The number, age, and place guards are otherwise unchanged.

- **Add a chart, CSV download, and table links** ([#7](https://github.com/tottedk/statistikbanken-mcp/pull/7), 2026-10-31). When one answer has several periods in the same series, the page draws a line chart. Several places become several lines. CSV downloads the rows as UTF-8 with a BOM, semicolons, and a decimal comma. Each table links to `https://www.statistikbanken.dk/` plus the table id. A number in the prose was kept when it appeared in the question or anywhere in that turn's tool results. An invented figure replaced the prose. Digits inside a table id are not figures. The question decides the age: `80+`, `over 80`, and `80 år og derover` become `sum_from`, and `0-17`, `mellem N og M`, or `børn` become `sum_range`, replacing the ALDER codes the model sent. If the fetched age or municipality is a different one, the answer says so and the cards, chart, and CSV are hidden. The page's own line includes the dimensions. A model timeout, including one wrapped in an exception group, is HTTP 504.

- **Add a local web page over the MCP server** ([#6](https://github.com/tottedk/statistikbanken-mcp/pull/6), 2026-10-31). A Danish page on 127.0.0.1 asks one question and shows the answer, the numbers (table, period, unit), and each MCP tool call. The page is an MCP client over stdio. The model is an OpenAI-compatible chat-completions endpoint: Ollama by default, or xAI when `--llm xai` and `XAI_API_KEY` are set. In-memory limits cover question length, a per-address rate, and a daily cap.

- **Add an MIT licence** ([#5](https://github.com/tottedk/statistikbanken-mcp/pull/5), 2026-10-31). Adds `LICENSE`, Copyright (c) 2026 Thomas Jensen. `pyproject.toml` sets `license = "MIT"` and `license-files = ["LICENSE"]`. The README links to that file.

- **Sum a closed age range and show what a table measures** ([#2](https://github.com/tottedk/statistikbanken-mcp/pull/2), 2026-10-31). `hent_data` can total a closed run of numeric codes. `sum_range` `{"ALDER": ["0", "17"]}` sends the API's own `sum()` and returns one figure labelled `0-17`. `sum_from` is unchanged. Each data result includes `title`, `description`, `unit`, and `periods`. A search for associations still returns `IDRFOR01`, whose title is sports clubs and memberships, not every association and not unique persons.

- **Add a Statistikbanken MCP server** ([#1](https://github.com/tottedk/statistikbanken-mcp/pull/1), 2026-10-31). An MCP server (stdio) for Danmarks Statistik's open Statistikbanken API. No API key. `find_tabel` searches the published table list by id, title, and variable name. `tabelinfo` returns variables and value codes, and collapses long numeric runs such as ages 0–125. `hent_data` fetches rows. Unknown table ids and value codes become a short message naming the bad code and which tool to call next. Ages in FOLK1A are single years, so `sum_from` (for example `{"ALDER": "80"}`) sends the API's own `sum()` and comes back as one figure labelled `80+`. Recorded responses from the live API back the unit tests. Live tests, including one stdio client session, hit `https://api.statbank.dk`. CI runs ruff and pytest.

### Changed

- **Tighten the web prose number guard to fetched rows** ([#9](https://github.com/tottedk/statistikbanken-mcp/pull/9), 2026-11-01). A number in the model's prose is kept only when it is in the question, a fetched `hent_data` value (Danish formats included), a period or row label from those rows, the fetched table title, or a variable value the model passed in that turn's `hent_data` arguments. Figures that show up only in `tabelinfo` or `find_tabel` are suppressed. The prompt tells the model to name areas and categories rather than quote their codes.

- **Log flagged numbers and ask for start and end values only** ([#8](https://github.com/tottedk/statistikbanken-mcp/pull/8), 2026-10-31). When the number guard drops a multi-series answer, the server logs the flagged figures at INFO and does not log the sentence. The system prompt tells the model to quote only the first and last value of each series, and not to compute a difference or a percentage.

- **Rewrite the README for a first read** ([#4](https://github.com/tottedk/statistikbanken-mcp/pull/4), 2026-10-31). README only. It states what the server is, shows three calls checked against the live API on 31 October 2026, and records the 50-question run plus the limits that remain. No software licence was added. The data note points at Danmarks Statistik's own CC BY 4.0 terms.

- **Make table search and data errors usable** ([#3](https://github.com/tottedk/statistikbanken-mcp/pull/3), 2026-10-31). The three tools stay the same. `find_tabel` ranks partial matches, a small synonym list (`bruttoledighed`, `huspriser`, `husdyr`, `population`, `indbrud`, and a few English equivalents), and FOLK1A municipality names. A miss returns an error that suggests a broader query. `hent_data` accepts value labels, suggests close matches, names the latest period when a period is missing, fills a required total into `defaults`, and lists codes when a required variable has no total. `sum_range` also adds an explicit list of codes. If the API refuses the sum, the rows are fetched and added here. A trailing 0 in a series is marked `unpublished`. `tabelinfo` summarises time as first, last, and count, caps long value lists, and takes `values_filter`. Value labels are not indexed for every table, only FOLK1A areas. Equal search scores keep catalogue order.
